# Scythe
An early 2021 revival written in JavaScript

#### Scythe is still in development and is not ready for production!

---

# Setup
1. Go into Command Prompt or Terminal and type `npm install` to build the server.
2. Run `choco install mkcert` with administrator permissions.
3. Run `mkcert -install`.
4. Run `mkcert -cert-file cert.pem -key-file key.pem localhost 127.0.0.1 ::1 <your-lan-ip>`
5. Go into Command Prompt or Terminal and type `npm run start` to start the server.
